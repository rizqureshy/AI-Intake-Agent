# Selectable Options

The agent should not rely only on open-text questions. Where helpful, present **selectable
options** (quick replies / multiple-choice question nodes) and offer **sample answers** the user
can accept, edit, or rewrite. Store each selection in a variable (see
[`../data/intake-schema.md`](../data/intake-schema.md)).

## Sample answers / suggested wording

Beyond fixed options, the agent may generate **sample wording** for the user to accept, edit,
or rewrite — for example a stronger problem statement or a stronger project title.

**Weak title:** "RFP Agent"
**Improved title:** "AI-Assisted RFP Response Automation to Reduce Manual Bid Effort and Improve
Response Consistency"

After offering generated wording, ask: *"Would you like to accept this wording, edit it, or
rewrite it?"*
